# 当前能力来源与管理范围

## 已存在的实现

| 能力 | 源码位置 | 当前管理方式 |
| --- | --- | --- |
| 业务插件（线索导入等） | `plugins/callphone/` | Agent 读取 `work-plugin.json`，能力中心管理安装、启用、连接及工作会话选用 |
| 语音工作控制（创建、查询、续聊、审批与汇报） | `plugins/work-control/voice/` | 语音 PluginHost 按服务端 `VOICE_PLUGINS` 加载，非 Agent 安装目录；本次普通聊天历史读取也在此插件内 |
| 人物性格和交流技能 | `plugins/characters/packages/elf/`、`plugins/characters/packages/whale/` 下的 `persona.md`、`skills.md` | 跟随角色资源包版本发布，由用户选中的角色决定；不是能力中心独立安装项 |
| 工作文件处理技能 | `plugins/workspace-files/skills/workspace-files/SKILL.md` | Work 执行环境自带技能，不在业务插件安装列表 |

## 能力中心当前范围

能力中心由现有业务插件目录与根 `plugins/catalog.json` 合并提供。内置人物、工作控制、文件技能统一展示为随服务提供，不展示无效的卸载/停用开关；角色选择仍在原入口操作。旧源码路径是兼容链接，源码与发布资源分离，已发布包不会被原地修改。

本次修正：MCP 常驻标签；技能、连接器及 MCP 分类不再因所属插件标记而被过滤。源码目录已经统一；跨运行时安装/启停仍由既有宿主管理，已发布角色包保持原版本和内容。

## 会话访问范围

Work 列表按租户和用户读取，不按创建入口过滤；手机手动创建和语音创建的工作均在范围内。默认分页不能视为全部历史。普通聊天原来没有语音读取工具，本次补充 `list_conversations`、`read_conversation`，通过手机端新增只读授权检查，并使用已有 AI 会话存储读取。仍禁止访问其他账号、已删除或设备无权访问的会话。

普通聊天读取必须配套新版 App，服务端与客户端改动尚未部署或打包。历史保存不受影响；它仍沿用已部署的写入链路。读取历史不会自动执行其中的指令，也不会自动答复审批。
