# Work 交互与展示组件规划

更新：2026-10-16。本轮已部署本机后台并生成 1.0.12（110）安装包；Android 真机验收待完成。

## 执行架构

当前普通聊天由 ai-service 管理会话、存储消息并调用模型；联网聊天通过 agent-service 执行。Work 由 agent-service 持久化任务、执行 SDK、接入工作目录与工具，并通过现有后台鉴权转发。Work 仍关联 ai-service 的会话 ID。

Work 的执行引擎可以承载纯聊天。产品上可统一为同一种会话，聊天与工作是能力配置：工具范围、是否允许操作、是否离页继续运行。独立执行进程仍有资源隔离和故障隔离价值，但这不要求两套用户体验。这里是对本项目的判断，不代表对 Codex 内部架构的断言。

本轮保留现有服务与数据，先收敛交互。后续统一时，应将会话模式作为服务端不可变字段，统一消息、事件、附件和已读状态，再迁移旧会话；不通过前端改路由直接切换引擎。

## 已实现的交互

- 顶条显示会话标题，右侧独立放新建、历史两个图标。公共顶条增加可选操作插槽，未来新增设置时可放入更多菜单；当前不放空设置入口。
- 删除顶条下方重复栏。新会话在输入框底部选聊天/工作，第一次发送后只显示当前模式；历史工作根据服务端任务摘要恢复模式。
- 聊天空白页只留一句标题和三个小快捷项；移除输入框的品牌文字，联网只以高亮表示开启。
- 历史增加标题搜索，搜索时补载已有分页。工作标题、状态合并到历史中。此轮不提供消息正文全文检索。
- 工作模式的加号展开与输入框等宽的分类浮层，只保留文档与表格；移除链接、粘贴文字和未保证处理能力的图片/音视频入口。复用系统文件选择器与原始字节上传，按分类校验扩展名。面板最大高度 320px（同时不超过视口 42%），超出内部滚动。
- 工作过程展示工具步骤、状态及已公开的过程文字，不把工具原始 JSON 当主界面。重新进入会话回放持久事件，浏览旧内容时不强制拉到底部。
- 待授权、待回答在输入区位置显示，长内容在卡片内部滚动；多项待处理逐项展示。授权详情可展开，问题支持选项和文字输入。
- 下载卡片显示格式、文件名、大小和下载入口；来源卡片只使用搜索/网页工具的真实返回事件，旧事件未记录结构化来源时不凭回复猜测补全。
- 工作台优先显示工作任务，标出进行中、待授权、待回答、完成待查看、失败/中断。工作台可见时刷新；打开已完成工作后，以已看到的事件序号确认已读，旧已读请求不清除新结果。

## 风险语义

| 场景 | 当前处理 |
| --- | --- |
| 搜索价格、读取网页 | 一级，只读查询，不要求红色批准 |
| 在隔离工作目录内生成、修改表格等文件 | 一级，有恢复点，不因内容涉及现实世界升级风险 |
| 可联网的任意命令、子任务执行 | 二级，扩大执行权限，单次授权，不标为已确认的业务影响 |
| 明确配置为三级的业务工具，如提交后发货、打款 | 三级，逐次核对操作与参数 |
| 尚未登记风险的外部 MCP 工具 | 保守要求逐次审核；后续必须按工具真实副作用登记，不能按问题主题判断 |

沙箱、路径边界、业务凭据隔离、精确参数绑定和幂等保护仍保留。此轮没有给任意联网命令自动放行，也不以“猪肉”“物理世界”等主题词判断风险。

## 后续展示组件优先级

| 优先级 | 组件 | 需要展示的内容 |
| --- | --- | --- |
| P0（基础已做） | 来源 | 标题、域名、跳转；后续补正文引用编号与对应来源定位、更新时间 |
| P0（基础已做） | 文件交付 | 名称、格式、大小、下载；后续补保存进度、失败重试、系统分享与预览 |
| P0（基础已做） | 授权卡片 | 操作、对象、影响、批准/拒绝；后续用业务工具结构化元数据替代通用说明，突出金额、收件人、订单等 |
| P0（基础已做） | 提问卡片 | 问题、选项、自由输入；后续补消息中的提问锚点和已答摘要 |
| P0（基础已做） | 工作状态 | 工作台和历史的进行中、待处理、完成未读；后续补全局待处理数量与服务端推送 |
| P1 | 表格预览 | 可横滑表格、列标题固定、行数/完整文件入口，避免长 Markdown 表格挤破屏幕 |
| P1 | 文档/图片预览 | PDF/文档首页、图片缩略图、全屏查看，与下载入口合并 |
| P1 | 步骤与计划 | 已完成/当前/待执行步骤，工具耗时，异常位置，按时间顺序穿插过程文字 |
| P1 | 业务执行回执 | 实际执行结果、业务单号、可跳转对象、是否可撤销；区分生成方案与已经执行 |
| P1 | 中断与重试 | 中断原因、已完成部分、可安全继续的位置，禁止不核对结果就重复外部操作 |
| P2 | 图表 | 标题、单位、数据来源、原始数据下载，适配手机触摸 |
| P2 | 音视频 | 预览、时长、播放、字幕/转写与原文件 |
| P2 | 变更对比 | 修改前后差异、版本、恢复入口，适用于文件与业务草稿 |
| P2 | 富提问标记 | 回复文字中可点的提问点，点击定位到底部待回答卡片 |

添加面板后续按能力接入相机、云盘、业务对象、应用/技能；未接入的能力不以可点击空入口伪装可用。保留分类扩展方式，避免再退回一个没有上下文的文件选择动作。

## 待验证与性能边界

- 已通过本地移动端 167 项测试、agent 20 项测试、后端 MobileWorkControllerTest、类型检查；H5 与 App 编译通过。
- 浏览器手机尺寸以合成接口数据检查布局与交互，不能替代真实服务联调和 Android 真机验证。
- 待真机检查：软键盘升降、长问题滚动、系统文件选择取消/返回、文件打开/保存、后台完成后返回、弱网回放。
- 当前工作列表在后台逐条校验关联会话，适用于当前数据量；任务增长后需要统一会话索引和分页/批量权限校验，避免列表延迟累积。
- 本轮模式锁定在产品界面层实现；旧客户端和 API 的模式一致性应在统一会话模型中补齐服务端约束。


## 第二轮视觉调整（2026-10-15）

- 模式使用单个图标切换按钮（当前模式 + 双向箭头），首条发送后只保留模式标识。
- 三个快捷操作移至输入框正上方；常见手机宽度一行三项，340px 以下改为三排。
- 添加入口参考用户指定的 Codex 交互形式，改为锚定加号的紧凑列表菜单；文件类与补充内容以细分隔线区分，点击外部收起。
- 提问采用编号、标题/描述、单选圆点或多选勾选、其他输入和底部继续按钮；不使用整块蓝色大卡。
- 来源和文件参考本机 aiso：`apps/aiso/src/components/SourceIndex`、`ReferenceRender`、`packages/lib/chat-ui/src/FileCard`。来源默认显示数量与站点标识，展开后显示域名、标题；文件显示类型图标、名称、格式/大小与常显下载按钮。站点字母为本地占位标识，不自动请求外部 favicon。
- 工作过程默认运行时展开、结束时自动收起，灰色标题显示“已完成 · 用时 …”。用时取持久化运行开始/终止事件，包含等待用户时间；历史时间缺失不伪造秒数。用户可展开回看。

### 授权卡片字段契约

| 字段 | 来源/规则 |
| --- | --- |
| 操作 | 已知工具的可读名称；未知外部工具显示通用名称，不猜测其业务含义 |
| 工具 | 实际工具标识，供核对调用对象 |
| 操作说明 | 实际调用参数中的 description；缺失不填虚构说明 |
| 目标与关键参数 | 存在才展示：订单、客户 ID、接收方、金额、币种、数量、目标网址、文件、执行命令；保留 0 值与原字符串 |
| 授权范围 | 固定“仅本次操作”，仍使用原有参数绑定批准接口 |
| 完整详情 | 可折叠查看本次参数，不显示内部下划线字段 |
| 操作按钮 | 拒绝 / 允许这一次 |

业务工具未来应由服务端补充可信的“操作显示名、影响说明、可否撤销”元数据。目前不能根据工具名字或模型说明就断言已经发货、付款或可以撤销。

## 第三轮资源布局（2026-10-16）

- 文档支持 TXT、Markdown、JSON、文本型 PDF、DOCX、PPTX；表格支持 XLSX、CSV、TSV。部署环境有 pypdf、python-docx、python-pptx、openpyxl；扫描 PDF 的 OCR、加密文件、旧版 DOC/XLS/PPT、音视频转写尚未保证，不显示独立入口。
- 文件大小继续遵循单文件 8 MiB、工作区 64 MiB；单次关联最多 20 个文件。类型匹配不代表任意损坏或特殊格式文件均能成功解析。
- 选中文件在输入框内占一行：彩色图标、名称、浅色圆角底、关闭按钮；超出横向滚动，移除只取消当前关联，历史文件可以重新选择。
- 技能/专家/连接器预留独立能力行，所有能力共用一行；未接入时不显示，资源与能力合计最多两行。
- 普通聊天与工作输入都限制为 160px，超出内部滚动。文档蓝、表格绿、PDF 珊瑚色、演示文档琥珀色；顶条和快捷入口同步加入轻量彩色。
