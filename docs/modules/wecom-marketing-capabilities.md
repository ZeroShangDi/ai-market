# 企业微信营销能力盘点与项目规划映射

更新日期：2026-10-05。本文梳理企业微信官方产品/API可支持的营销链路，并标出 Call Phone 项目文档已规划的部分。企业微信管理后台开关、应用类型、企业认证、客户联系权限和接口版本会影响具体可用能力；本清单不表示当前租户已开通或本项目已完成对接。

## 判断口径

- **已规划**：项目文档已有页面、数据/API契约或实现批次。它不代表真实企微联调完成。
- **部分规划**：已规划某个环节，但真实触达、回执、数据来源或自动化尚未纳入。
- **未规划**：现有页面契约未覆盖，后续需明确产品范围。
- 能力以企业微信管理后台和官方 API 权限为准。企业微信官方客户联系接口文档入口：[客户联系 API](https://work.weixin.qq.com/api/doc/90000/90135/)。群发到客户群官方接口说明：[创建企业群发](https://work.weixin.qq.com/api/doc/90000/90135/92134)。会话存档说明：[会话内容存档](https://work.weixin.qq.com/api/doc/90000/90135/91774)。官方文档站部分页面需登录；开发前应以目标企业后台展示的权限与当前文档为准。

## 能力全景

| 营销阶段 | 企业微信可做的事 | 项目映射 | 当前边界/缺口 |
|---|---|---|---|
| 获客入口 | 员工联系我二维码/按钮、客户群加入二维码、渠道活码；按员工/场景承接添加客户或进群 | **部分规划**：渠道/员工/门店/识客活码、获客链接、组合海报、平台渠道（拓客模块） | 活码配置管理已有接口；公开落地、企微侧真实码创建/更新、扫码事件、欢迎语触发、访客授权与归因仍未接通。当前不可将预览二维码用于投放 |
| 添加客户与归属 | 客户添加事件回调、外部联系人列表/详情、跟进成员、添加来源、备注描述、标签等 | **已规划**：企微客户页、按员工同步、字段权限、敏感信息显式读取 | 项目已有本地只读同步实现契约；企业授权/数据库联调待完成。缺少添加事件实时接入、离职继承/转接工作流和跨渠道归因关联 |
| 客户标签与分层 | 企业标签、员工个人标签；基于客户属性/标签/跟进员工筛选人群 | **部分规划**：客户运营人群条件含跟进成员与标签；企微客户资料含标签 | 标签目录管理、同步/映射、标签规则自动化未形成独立契约；本地人群估算只依据已同步快照 |
| 客户群运营 | 群列表、群主、群成员、群状态与变更；群二维码获客；群发任务可要求群主确认发送 | **部分规划**：客户群只读同步、群成员详情；客户运营草稿和审批 | 不改群成员、不创建/解散群、不发群消息；群发触达与员工确认/逐群回执未接。官方群发并非无审核的后台直接群机器人推送 |
| 一对一触达 | 员工在企微客户端与客户聊天；第三方应用是否能代发取决于具体产品/授权及可用接口 | **未规划真实发送**：AI话术可复制；客户运营尚不含单聊发送命令 | 不应把客户联系基础 API 等同任意代员工发送私聊。需按官方当前接口权限核验消息推送场景、员工确认要求和可回执程度 |
| 企业群发给客户 | 管理端创建群发任务，选择成员/客户范围、文本/图片/链接/小程序等素材；成员在企微客户端确认发送；可查任务及执行结果（受官方频次/范围约束） | **部分规划**：客户运营活动草稿、估算、提交审批、撤回及审计 | 目前明确不触达客户，也没有 `send` 权限、员工确认状态和官方发送结果同步。后续需在审批通过后新增独立发送流程 |
| 群发给客户群 | 创建客户群群发任务，选择客户群/群主和素材；通常由对应群主在客户端确认；可查员工执行状态 | **部分规划**：客户群投影 + 客户运营 | 同上，真实发送、群主确认、频率限制与分群结果未接 |
| 客户朋友圈 | 企业统一创建内容/任务，指定可见员工范围；员工确认发表；管理侧查看发表记录/互动信息（能力随企业版本/授权变化） | **未规划** | 无朋友圈页面、内容日历、审批、发表状态/互动回执契约。需先验证目标企业后台是否开通及官方 API 可用范围 |
| 内容与素材 | 文本、图片、视频、文件、网页链接、小程序等可用于官方支持的群发/朋友圈场景；素材上传与素材管理受接口限制 | **部分规划**：知识库/话术、组合海报；客户运营内容草稿 | 未规划企微素材库同步、媒体上传、素材审核/有效期、消息内容类型白名单及模板版本 |
| 活动与转化 | 以渠道/员工/活动参数归因；通过线索/客户建档、跟进、转化及活动结果复盘 | **部分规划**：渠道数据、线索池、跟进、转化记录；企微来源待打通 | 企微添加事件和消息互动未接入归因链；现阶段渠道报表不提供虚构访问量，实际触达转化漏斗不完整 |
| 会话服务与销售过程 | 经告知/同意后启用会话内容存档；按权限获取会话内容，支持审计、质检、服务风险识别 | **部分规划**：会话存档、服务质检、风险预警、AI总结/建议 | 页面与本地数据契约已规划；官方存档 SDK、员工告知/外部联系人同意、采集 worker 未接。服务质检只支持已有通话数据，不代表企微会话已质检 |
| 数据与权限治理 | 按企业、应用、成员可见范围授权；配置可信 IP、回调、密钥；限制敏感字段及存档访问 | **部分规划**：扩展服务配置、字段权限、加密、租户隔离和访问审计 | 连接配置保存不代表连接成功；需接入回调验签/解密、token 管理、权限探测、密钥轮换和断连流程 |
| 自动化运营 | 根据新增客户、标签、阶段、未回复/跟进时间等触发任务；自动分配/提醒/待办 | **部分规划**：线索分配、跟进事项、活动审批 | 没有企微事件驱动规则引擎、自动欢迎语编排、自动标签/分群、营销旅程和频控策略 |
| 效果分析 | 任务覆盖人数、员工执行率、送达/失败或完成状态（以接口实际返回为准）、新增客户、群成员变化及转化结果 | **部分规划**：渠道数据、活动人群快照估算 | 没有企微群发任务与结果报表、朋友圈互动报表、触达漏斗；指标可得性需接口实测，不能承诺消息阅读/点击数据 |

## 项目已有规划的企微页面

当前项目规划菜单覆盖：**企微客户、客户群、客户运营、会话存档**。依据 `docs/contracts/page-implementation-status.md` 和 `docs/modules/customers.md`：

1. **企微客户**：真实列表/详情/员工选项/按员工同步任务的页面与后端契约已写；本地密文投影和权限控制已实现到代码层，待目标企微授权及数据库联调。
2. **客户群**：真实只读列表/详情/同步契约已写；群和成员密文投影、解散状态快照已规划/实现；当前不添加或移除成员，也不发送群消息。
3. **客户运营**：加密草稿、受众选项、本地快照估算、提交审批、撤回和审计已写；**实际企微触达明确未实现**，没有发送权限或虚构成功状态。
4. **会话存档**：只读分页、受控正文查看、访问用途审计、保留策略、手动分批物理清理及每 15 分钟自动保留清理已写；**官方 SDK、成员同意和采集 worker 未接入**，同步状态仍应为未启用。
5. **拓客联动**：活码/链接/组合海报管理与渠道数据已规划或有配置接口；公开二维码落地、扫码和企微添加客户事件归因尚未实现。

因此目前能确认的是“项目已规划并实现了部分本地页面/数据契约”，不能确认任何企业微信真实营销触达链路已经完成端到端验证。

## 建议的验证顺序

1. **先验证企业授权与只读同步**：企业/应用身份、客户联系权限、授权员工范围、回调和可信 IP；读取少量测试客户与群。
2. **再验证获客归因**：生成测试用联系我/入群码，扫码添加测试微信，确认新增客户事件、员工归属、渠道来源能落入本地数据。
3. **验证运营任务但不发给真实客户**：选内部测试员工和测试客户/测试群，核验任务创建、成员确认、官方状态/回执以及撤回边界；先明确企业微信侧的频次额度。
4. **最后验证会话存档**：确认购买/开通资格、告知和外部联系人同意，在专用测试员工与测试外部联系人间产生测试会话，验证取数、解密、用途审计、保留与删除。
5. 每一步记录企业微信 API 返回的状态码/稳定错误码、任务 ID 和时间；严禁把 access_token、secret、私钥、完整客户手机号或会话正文贴到聊天或普通日志。

## 为操作验证需要提供的资源

请准备专用测试企业或可控的企业微信测试租户。优先由企业管理员创建最小权限的自建应用/客户联系应用并亲自录入密钥；不要把 Secret、token、会话存档私钥直接发在聊天里。连接信息应通过项目的加密配置入口或受控密钥渠道提供。

| 资源 | 用途 | 提供方式/注意点 |
|---|---|---|
| 企业微信企业 ID（CorpID）及企业主体/版本信息 | 确认企业、客户联系与朋友圈等能力开通状态 | ID 可经受控配置提供；请注明是否测试企业、认证状态及管理员联系人 |
| 自建应用 AgentId、Secret；客户联系 Secret 或对应应用授权 | 获取成员、客户、客户群及群发接口权限 | 管理员在系统中录入；仅给最小权限；按项目安全入口提交 Secret，不在聊天粘贴 |
| API 权限清单与授权截图/文本 | 核实客户联系、客户群、客户标签、群发、客户朋友圈、会话存档分别是否开通 | 截图请遮住密钥、二维码、客户姓名和手机号；标明可用成员范围 |
| 测试成员名单及 UserID、部门/角色、客户联系权限 | 验证员工范围同步、群主确认和权限过滤 | 提供 2–3 个内部测试成员即可，避免真实客户数据 |
| 测试外部联系人和客户群 | 验证客户同步、标签、人群估算、群成员投影 | 使用员工/企业自有测试微信，群内成员均知情；不要导入生产客户名单 |
| 测试渠道/活码目标与公开 HTTPS 域名 | 验证二维码、回调、跳转、归因链路 | 提供可控域名、TLS/回调配置权限及一个内部测试落地页；当前项目公开落地服务仍需开发 |
| 回调 URL 的可达公网 HTTPS 环境及可信 IP 配置权限 | 接收客户变更/添加事件并验证来源 | 需能从企业微信服务器访问；提供测试环境地址与部署窗口，不通过临时个人隧道承载生产数据 |
| 会话存档开通状态、SDK、RSA 私钥保管安排与告知/同意流程 | 验证会话内容获取、解密、授权与保留 | 私钥必须留在部署密钥管理处；提供是否开通、授权员工范围及测试同意流程，不发送私钥 |
| 项目测试环境 | 连接本地后端、数据库迁移、回调与日志核验 | 提供测试 API Base URL、TLS 证书/反向代理信息、数据库版本及部署窗口；凭据单独安全注入 |
| 验收用例和允许动作 | 控制是否只读、是否创建任务、是否允许测试成员确认发送 | 明确测试客户/群、时间、消息内容、是否可实际送达；默认先用内部测试对象 |

**最低启动包**：测试企业 + 管理员协助 + 客户联系权限 + 两名测试成员 + 一个测试外部联系人 + 一个测试客户群 + 项目测试环境。若先做只读同步，不需要先提供朋友圈或会话存档权限；如要验证发送，另需明确允许的内部测试接收对象和管理员批准的运营任务。
