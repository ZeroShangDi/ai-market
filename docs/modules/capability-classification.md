# 能力中心归属与状态约定

每个发布包只声明一个 `catalogType`，默认 plugins。主目录仅显示无 parentId 的条目；一个插件内附带的技能、连接器与 MCP 只在插件详情出现，不重复生成其他分类的根卡片。包所在源码目录与页面分类无关。

| 分类 | 归属标准 | 状态与操作 |
| --- | --- | --- |
| 插件 | 多能力组合并共享安装生命周期，例如客户业务、会话与工作 | 安装/卸载、启用/停用；查看包含的能力，账号连接在内含连接器处理 |
| 技能 | 可以独立交付的知识、工作指引或脚本，例如人物卡片、工作文件 | 安装/卸载、启用/停用；不显示账号或连接状态 |
| 连接器 | 对一个服务的连接和账号授权 | 只展示连接状态、连接/断开；已连接时显示账号，不提供安装/启用开关 |
| MCP | 独立接入并单独管理的 MCP 服务 | 展示工具和真实管理状态；插件内 MCP 只在插件详情出现，不因用了 MCP 协议自动生成独立根项 |

内置是来源标记，保留在相应分类，不强制归为插件。内置项当前随服务/角色提供，不伪造无法落实到执行层的卸载与开关；未来支持独立配置时再开放操作。独立技能的生命周期仍由同一包管理接口处理；插件附带技能只有自身启停，安装/卸载跟随父插件。

状态使用紧凑标签，详情标题下方、正文前放置；列表沿用卡片底部。灰色表示未安装/未启用/未连接，绿色表示已安装/启用可用/已连接；已启用但缺少必要连接用黄色“待连接”。未检查远端实时健康时不声称服务健康。连接器只有一个连接标签，技能不继承父插件的账号与连接标签。

WorkBuddy 将 MCP 归入连接器，见 https://open.workbuddy.cn/docs/connector 。本项目暂保留四类；没有独立服务时 MCP 分类为空，不把内置插件工具重复放入分类填充列表。专家是角色/领域任务编排的产品形态，未来需要时单独讨论，不把插件一律重命名为专家。
