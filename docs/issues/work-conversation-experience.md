# Work 对话页体验优化

2026-10-19。对比基于官方产品说明与本仓库检查，尚未完成竞品真机走查。

## 本轮实现

- 步骤优先采用具体动作说明，后到达的参数更新已有标题；文件仅展示名称，不直接展示命令和正文。每项最多两行，超出省略。
- 过程步骤、部分文字、文件按同一事件顺序保留；完成或中断不清空、不自动折叠，刷新重建同一轮回复。
- 每轮从开始到结束使用同一个回复容器，文件在生成的位置保留；来源按轮次归属，来源与回执详情的展开偏好在本机保留。
- 历史与工作台标题旁使用轻量「工作 / 聊天」标签，已有工作任务的会话标为工作。
- Android 本地副本存在时显示查看，重新进入和回到前台检查存在性，文件移除后恢复下载；网页端仍使用浏览器下载。
- Android 分享调用系统应用选择器，授予临时只读权限。微信是否出现、支持的文件格式及联系人选择仍需真机验证；打开面板不视为发送成功。
