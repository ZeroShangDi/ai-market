# 外部应用打开文件到工作会话异常

- 记录日期：2026-10-17
- 测试版本：Android 1.0.16（114）
- 来源：用户真机反馈
- 状态：待复现、待修复
- 2026-10-25 更新：用户仍反馈不可用。源码修正接收入口对 `Array.at` 的依赖，以及聊天列表加载时创建会话被拒绝的竞争；真实创建失败不自动循环，返回页面可重试。尚无连接手机，未确认这些缺陷是否覆盖用户此次全部现象；保持待真机复测状态。

## 操作路径

在其他软件中选择文件，使用「其他应用打开」选择本应用。

## 实际现象

用户观察到两种情况，是否属于同一原因尚不确定：

1. 出现类似「接收的文件暂不可用，请重新打开文件」的提示。用户原述为「接受文件咱不可用，请重新打开文件」，确切文案需核对。
2. 能进入工作页面，但短暂出现疑似「创建失败」的提示。提示消失较快，用户未看清，不能确定是否为会话创建失败。

进入后页面确实处于工作模式；文件看起来仍留在会话中。附件是否成功上传、能否发送、Agent 能否读取原始内容尚未确认。

## 预期行为

其他应用打开受支持文件后，进入工作会话并展示待发送附件；接收、创建会话、上传和发送状态一致。失败时保留可恢复的附件，明确失败阶段并提供重试，避免短暂提示导致原因无法辨认。

## 后续核对

- 外部接收成功后 pendingFiles 的返回值及原生模块桥接解析是否正常。
- 冷启动、热启动以及登录恢复期间，接收扫描与工作会话创建的执行顺序。
- 文件已展示但创建或上传报错时，界面状态与服务端实际资源是否一致。
- 提示出现的具体阶段和固定错误码；遵循诊断日志规范，不记录文件正文、原始路径或凭据。

目前仅记录用户现象，以上检查方向不是已确认根因。原应用、文件格式、手机系统及冷/热启动条件待后续复现补充。
