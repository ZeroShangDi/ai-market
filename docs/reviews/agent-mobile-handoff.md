## 本次文件

- `apps/call-phone-uni/src/types/ai-task.ts`：独立平台任务、事件、待确认跟进建议、文本资料和产物契约。
- `apps/call-phone-uni/src/services/ai-task.ts`：复用现有认证请求；任务列表、提交、查询、取消、确认、取产物；可见期间轮询；离页停止观察而不取消服务端任务。会话切换、账户/设备变更丢弃迟到响应；不确定提交保留同一个请求 ID 供重试；事件按序去重；确认/取消和迟到轮询不能把终态恢复为运行中。演示模式禁止真实请求。
- `apps/call-phone-uni/src/services/ai-task-files.ts`：H5 选择文本文件、Blob 保存结果；App 尝试平台文件选择并通过 plus.io 读取，无可用选择器时明确提示粘贴。App 产物保存到应用私有目录，调用系统文本阅读器；没有阅读器时提示可复制内容。
- `apps/call-phone-uni/src/components/AgentTaskPanel.vue`：对话中的可折叠“资料任务”入口；有权客户分页选择、`.txt`/`.md` 或明确标记的粘贴资料（最多 64 KiB UTF-8）、任务要求、提交、事件进度、取消、完整待办参数确认、产物预览/复制/保存。展示北京时间。
- `apps/call-phone-uni/src/pages/ai-chat/index.vue`：仅新增组件引入、scroll-view 内入口和页面可见性传递。保留该文件已有未提交修改及原文字对话行为。
- `apps/call-phone-uni/tests/ai-task.test.cjs`：8 个新增测试，覆盖离页/恢复、会话与身份迟到响应、幂等重试/重复点击、提交中离页、确认/轮询竞态、事件回放、资料 UTF-8 限制、演示模式及 REST 路由。

## 续做验证与修复

- 增加 `confirmation_pending?: boolean`，与 Java 持久业务回执配合。任务即使处于取消态，只要服务返回已提交待办 ID 和 pending 标记，显示“已创建，结果正在同步”并提供同一确认接口的核对入口；普通取消任务不能借此创建待办，已提交待办不能再通过取消按钮误导为可撤回。
- 提交/确认/取消期间暂停轮询与手动刷新，结束后恢复观察，防止在途读请求覆盖操作结果或错误。

- 附件名称限制按包含扩展名的总长度 120；资料 NUL 和孤立 Unicode 代理字符不提交；H5 使用 fatal UTF-8 解码避免把坏字节静默替换。App 若系统解码产生替换字符则明确提示转换编码或使用粘贴资料。
