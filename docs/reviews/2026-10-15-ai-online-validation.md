## 完成结果

联网和资料任务已经部署到本机真实服务，手机仍使用原有后台入口。连续实际验收完成：扫码范围会话和设备认证 → 真实 DeepSeek 联网 → 来源和历史保存 → 提交客户资料任务 → SDK 查询授权客户快照/读取附件 → Markdown 报告 → 手动确认 → MySQL 事务 → PC 端读回。

搜索使用官方 Agent SDK 的内置 WebSearch，并非模拟联网。只开放搜索工具，搜索结果中提取真实来源；没有来源或执行未正常结束时明确失败。普通聊天接口保持兼容，手机默认开启联网但可关闭。搜索和回答进度独立于持久化正文，来源随正文保存与回放。

资料任务只接收 UTF-8 TXT/Markdown 或粘贴资料，最多 64 KiB。生成待办建议后等待用户确认，模型不能直接写入业务数据库。确认事务创建唯一回执与待办，重复确认复用原待办。

## 复用与替换入口

联网及任务执行复用 Claude Agent SDK，Markdown 复用 TDesign，Android 选择文件复用系统 SAF，APK 复用 apktool/zipalign/apksigner。供应商对话协议隔离在 ModelGateway；联网执行隔离在 createWebChatExecutor 与内部 SSE 契约；展示复用统一 Markdown 点击适配器。更换 SDK/搜索供应商或渲染组件时，可保留会话、任务、确认事务和手机 API。业务校验与回执留在现有服务，不交给模型或通用库。
