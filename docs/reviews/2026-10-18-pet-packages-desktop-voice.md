# 桌面语音与按需角色包：开发验证

状态：未发布、未打包、未真机验收。保留原 App 语音入口。

## 实现

- Android 短暂透明授权 Activity 启动 microphone foreground service；WebView 媒体会话归服务管理，宿主 onHide 仅关闭 App 内语音。长按菜单和服务通知可关闭桌面语音。不是依靠隐藏原 Dialog 维持录音。
- 「我的 → 语音」新增两套角色资源，下载/校验/应用/删除独立于业务；空安装不带动画视频。全部原视频移到仓库资源目录，未丢失源资源。
- 人物卡、交流技能、音色参考和动作由同一版本选择；文字聊天和语音查询均读服务端发布的文件，不接受客户端任意提示词或文件路径。
- 查询工作动作通过资源映射；结束、插话和关闭复位。工作任务确认与完成通知已在后续本轮实现，见 [后台任务桥接验证](2026-10-18-voice-background-work.md)。
- 用户选择保持当前静默退出机制，不开启常驻监听。
