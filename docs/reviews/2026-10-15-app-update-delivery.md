# 应用更新与变更日志交付记录

日期：2026-10-15（北京时间）。范围：先完成不依赖服务器的部分，独立分发地址和管理员后端暂未建设。

## 已完成

- 我的页面使用独立 AppUpdateRow，灰字显示当前版本，右侧「检查更新 / 更新」，显示下载/校验/安装进度，保留安装权限设置入口。
- 手工无更新提示「已经是最新版本」，有更新只切换按钮；自动检查弹出版本、更新内容和「更新 / 跳过」。跳过同版本持久保存，手工检查仍可更新，新版本重新提示。
- 下载校验后直接请求系统安装；返回前台先核对真实版本，再执行检查频率限制，避免一小时限制导致安装状态不能恢复。
- 移除通话/未保存结果的安装许可及更新对外呼的拦截，更新核心、交互和接入均不依赖业务模块。配对/退出等原有业务保护不属于本次更新流程。
- 源码版本递增为 1.0.8（106），本轮未发布或交付新的 APK。
- 新增根 CHANGELOG.md 和 AGENTS.md 规则；pre-commit 检查暂存区中代码变化与实际新增日志条目，当前仓库 core.hooksPath 已配置为 .githooks。未暂存/删除/仅改标题的日志不能满足检查；纯 Markdown 文档可免。
- 发布工具复用现有清单签名实现，校验真实 APK 的包名、版本、单一架构和基准证书，读取同版本 CHANGELOG，生成不可变 APK 地址、签名清单及客户端公开环境配置。禁止版本回退和同 versionCode 替换不同 APK。
