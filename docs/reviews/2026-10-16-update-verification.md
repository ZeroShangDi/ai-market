# Android 更新安装包校验兼容修复

- 用户反馈：更新下载后显示“安装包校验失败，已禁止安装”。
- 已确认发布文件的完整下载、SHA256、APK 签名与基准一致；没有连接的调试手机，因此未取得此次失败的原生调用现场，不能将模拟回归等同于真机定位。
- 发现校验适配器直接读取 PackageInfo 字段及签名，没有复用身份读取的 Native.js 回退；原生字段返回 null 时会误判，Java 证书数组也不一定具有 every 方法。
- 修复：文件映射常量、包名、版本、证书字段增加兼容读取；版本支持 getLongVersionCode；证书数组转为 JS 数组并核对同签名。文件大小、摘要、包名、版本、签名所有约束保留。
- 失败提示按阶段区分；诊断仅记录阶段、固定错误码与版本号，不记录原始文件路径、证书内容或原生异常正文。
- 169 项手机端测试、类型检查及 App 编译通过。新增模拟字段返回 null、Java 数组、损坏文件、错误版本/包名/证书、接口异常回归。
- 生成 1.0.13（111），原生代码和签名证书与 1.0.12 一致。SHA256：`42443e174209ac5b6a82de788be48ecce263b48cfaaefe859db2e9386363928f`。
- 旧客户端自身校验失败时无法靠新清单修复本地代码，需从公开 APK 地址手动覆盖安装一次，不卸载原应用。系统仍会验证 APK 签名。真机覆盖安装和新适配器验证待用户确认。

- 已发布签名更新清单及 APK；通过手机 Tailscale 地址验证新版发现、完整下载、SHA256、证书和 HEAD/Range，通过。此检查不执行 Native.js 真机调用。
