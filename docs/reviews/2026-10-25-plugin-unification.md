# 统一插件与待办恢复实现记录

本轮 Agent、AI 和 Mac 语音服务已于 2026-10-25 部署；手机 1.0.23（121）已完成账号云端证书安心打包并发布，发布结果见 [发布验证](2026-10-25-release-1.0.23.md)。保留原有工作区修改。

## 已实现

- 根 `plugins/` 成为业务、Work、人物素材与工作文件技能的源码位置；4 个旧入口为兼容链接。114 个角色素材文件逐一对比 HEAD 摘要，内容未变。
- Work 和客户业务提供官方 MCP SDK 的 stdio 服务。普通客户端使用 Work 网关账号/设备身份；业务内部桥只供受管理部署，不分发内部令牌给普通客户端。外部问题/批准通过 MCP 用户表单提交，不支持的客户端保留工作台处理。
- 能力中心合并根目录内置能力清单与现有业务插件生命周期；内置能力不暴露无效的卸载按钮。
- 语音工作列表使用 `/api/v1/mobile/work/sessions`，与页面同接口、同过滤，返回分页前总数。
- 底座 WorkStore：等待不占执行名额、不计执行超时；60 秒后保留待办并终止 SDK 查询。答复持久化、名额充足后恢复原 SDK 会话，重启恢复不会自动放行新工具调用。明确停止仍取消待办及排队消息。
- Docker 上下文调整为仓库根，专用忽略清单只包含依赖、源码及所需插件。没有修改已发布角色资源内容。

## 验证

- Agent：42 项通过，包括业务插件独立 MCP 预览/拒绝无用户确认的导入，等待释放名额、超时暂停、跨重启答复恢复、主动停止及身份隔离。
- Work 独立 MCP：4 项通过，覆盖标准客户端 schema/调用、真实 stdio 子进程协商、配置身份、用户表单答复不会被模型同意参数覆盖。
- 手机：231 项通过，类型检查及 H5 构建通过。
- 语音：43 项，42 通过、1 项按配置跳过网络测试。
- AI 会话服务：20 项通过。
- 已部署真实联调：语音/工作台列表一致、聊天历史、能力分类、公开搜索成功并有 8 个来源。
- 真实 WebRTC 合成语音创建 Work、记录保存及音频输出通过，240 个有效音频帧、无警告。
- Linux 容器真实模型提问、休眠、重建 WorkStore 后答复恢复原 SDK 会话并正确回复测试颜色通过；使用隔离临时目录。
- 插件元数据 JSON Schema、技能路径和 Work Agent Skill 校验通过；变更空白检查通过。

## 未验收与后续

已补充 Linux 容器真实模型提问与休眠恢复，重建 WorkStore 并复用持久化 SDK 会话；不能替代手机长时或跨机器断电验收。标准 MCP Client 互操作不等于每个 Codex/Claude Code 客户端均已登录联调。Docker Agent 与 AI 镜像已重建并部署。

语音卡碟与同音词错误继续为未解决问题。定时/事件调度、有限重试和预算保留后续 issue。记忆只登记官方开源服务接入定义，尚未部署用户隔离运行环境。跨宿主统一启停、独立 OAuth 登录和同一 Work 内步骤依赖调度仍未实现。
