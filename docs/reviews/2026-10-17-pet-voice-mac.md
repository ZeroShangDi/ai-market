# 宠物独立语音能力：Mac 首轮验证

日期：2026-10-17（北京时间）。开发实现，未发布 Android 安装包。

## 实际验证

- 独立 Python 3.12 / Pipecat 1.12.0 / MLX Audio 0.5.7 环境；Qwen3-ASR 0.6B 4-bit 按句识别，Qwen3-TTS 0.6B Base 4-bit 克隆合成，快速模型直接使用现有 DeepSeek 配置。
- ai-assistant 仅提供已有模型缓存、音色测试材料和接入经验参考；未修改其代码或环境。模型路径、参考音频、转写和凭据只在被忽略的本机配置/目录中，不随代码或客户端发布。
- 合成测试输入「你好，请简单介绍一下你自己。」识别结果完整匹配。识别约 1.205 秒，快速模型完整回复约 1.196 秒。TTS 首次首块约 4.017 秒，后续一次首块约 0.371 秒。单样本结果，包含冷/热状态差异，不是整体响应时间或性能承诺。
- 真实本机 WebRTC 媒体连接完成两轮交流，接收到实际音频帧。第一轮播报中送入第二段合成用户语音，观测到 `user_started → bot_stopped → bot_started`，说明旧播报停止并开始新回复。这里证明服务端打断链路，不等于手机扬声器已完成声学验收。
- 现有 Agent 容器未发布宿主端口；Mac 联调启动独立只读实例，复用现有执行代码，不打开生产 Work 数据卷。通过真实 SDK 文本请求验证转交成功，不搜索、不调用业务工具。
- 未采集真实麦克风；音频与问题均为合成测试材料。没有启用声纹或长期记忆。

## 1.0.19 手机测试版发布

- 默认改用 Qwen3-TTS 0.6B CustomVoice 4-bit 的 Vivian 预设女声，不读取克隆参考材料。单次合成按句拆为最多 120 字；MLX 空闲缓存上限 128MiB，并在每轮后清理。
- 新增用户最终转写与 TTS 本句开始播放的事件；受限 Android 桥接交由宿主更新原有宠物气泡，区分「你：」「她：」，不持久化、不写诊断正文。已通过实际媒体流的双方事件验证。
