## 本轮发现与修复

共三次真实模型任务。第一份报告将备注写为空，补充专家指令后仍出现空备注；继续核查发现输入适配主动把未提供的 notes 补成了空字符串。已修复适配：缺失字段保留为缺失，明确提供空字符串时保留空字符串；客户跟进/资料核查技能均明确“未提供不等于不存在”。

增加实际 HTTP 执行输入回归，区分缺失备注与明确空值；Agent 20/20 离线测试通过。最后一次模型报告明确表示本次未提供备注/历史资料，不能推断对应记录不存在。附件的预算、决策人和方案细节均保留待核实边界。

此前真实 SDK 本机模型替身测试捕获并修复 fallbackModel 与主模型相同导致初始化失败的问题；修复后四轮传输及工具链重新通过。
