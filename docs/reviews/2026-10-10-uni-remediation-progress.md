## 验证证据

- 移动端 `pnpm test`：34 项通过，0 失败。包括安全存储不可用时后台重试成功、结果弹窗再次保存不重复提交的回归。使用实际 TS 模块和边界替身；没有拨打真实电话。
- `pnpm type-check` 通过。
- `pnpm build:app`、`pnpm build:h5` 通过。App 资源不是 APK；Sass legacy API 提示仍存在。
- 生成 manifest：AppID `__UNI__D608100`，`plus.nativePlugins` 含 `leven-call`，`plus.distribute` 不含 `nativePlugins`。
- 后端定向测试：`CallPhoneMobile*Test,CallRecordingStorageServiceTest`，20 项通过；包括空通话列表不发起空集合 SQL 查询、新增观察事件的设备归属、时长范围、幂等冲突和不降级观测时长测试。使用本机缓存离线构建；Mockito 显式 javaagent 解决当前 JDK 下自挂载限制。
- `adb devices -l`：列表为空。
- `http://127.0.0.1:48080/actuator/health`：初查 3 秒超时；恢复 Docker 后返回 HTTP 200 / UP，约 0.134 秒，连续复查通过。
- Docker 虚拟机因历史存储错误停止，残留进程继续占用端口；结束失效进程并重启后恢复。没有删除/重置容器或数据库卷；虚拟磁盘历史错误仍需备份后离线检查。
- browser-bridge 提升权限后 daemon 可连接，但扩展 disconnected；前一轮内置浏览器确认工作台存在“待接派发 1”入口（合成数据）。继续检查我的页面时浏览器访问策略拒绝目标 URL，未绕过；完整页面验收仍未完成。
