## 资源接入方式

移动端在 App.vue 初始化独立资源域名与 src/modules/assets/manifest.json。该清单初始为空，不产生虚构云链接。

- AI 应用入口图标资源名：apps.ai-assistant.icon。
- 拨号应用入口图标资源名：apps.dialer.icon。
- 页面通过 AppAsset 解析名称，fallback 插槽使用本地 AppIcon。基础导航图标仍随安装包发布。

配置资源库与存储后，在项目根目录执行：

```sh
node tools/assets/cli.mjs upload ./ai-icon.png --name apps.ai-assistant.icon --config tools/assets/asset-config.json
node tools/assets/cli.mjs upload ./dialer-icon.png --name apps.dialer.icon --config tools/assets/asset-config.json
node tools/assets/cli.mjs export --out apps/call-phone-uni/src/modules/assets/manifest.json --config tools/assets/asset-config.json
```

设置 VITE_ASSET_BASE_URL 为真实可访问的资源域名，重新构建后生效。原图保留在资源库，不将上传凭据、管理清单或供应商地址导出到客户端。详细说明见 [图标能力](../../resources/icons/README.md) 与 [资源库](../../tools/assets/README.md)。
