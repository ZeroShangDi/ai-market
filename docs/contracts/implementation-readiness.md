## 关键约束

- 对外 API 保持产品契约 `/api/v1`，Yudao `/admin-api`、`/app-api` 与模块 Controller 作为内部接线，不让 PC/uni-app 绑定芋道内部 DTO。
- 只有应用中心第三级菜单是独立页面；详情、筛选面板、确认状态和非菜单交互均属于对应页面。
- UI 预览/Mock 必须显式标识；不将浏览器本地样例当成数据库持久化或生产接口成功。
- 客户姓名、手机号、录音与通话正文留在客户部署的数据平面；产品方控制平面只接收部署身份、授权和用量所必需的脱敏元数据。
- 关键业务验收须覆盖浅色主题的主页面、表格、弹窗、抽屉、下拉浮层；深色底板问题必须在对应页面验收时修正。
