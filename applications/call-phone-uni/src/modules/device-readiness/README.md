# 手机权限检查

权限由用户在设置页手动申请；App 启动不批量申请。分为基础、拨号与通话、高级、运行与更新。普通权限使用 Android Native.js，桥接不可用时显示未知；相机与麦克风支持 uni API 兜底。

文件访问沿用 Android 11+ 全部文件访问检查，旧版检查读取存储，仅在访问外部录音文件时需要。当前没有接入旧 leven-call 通话插件，自动录音只提供手动设置指引，不检测或承诺自动录音。电池优化检查不代表自启动已开启。无障碍仅提供系统入口和本应用服务状态检查，当前包未集成 Service。

权限从系统设置返回时重新读取；打开设置不等于授权。浏览器不提供原生操作按钮。
