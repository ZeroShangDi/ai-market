# 精灵桌宠动作素材 v3

工具：内置 image_gen。参考：elf-sheet-v2.png；透明 PNG；六列四行，每行六帧循环。

## elf-emotions-a-v3

```text
Use case: identity-preserve.
Asset type: production transparent sprite atlas for an Android desktop pet.
Input image: existing elf sprite strip is the identity and rendering-style reference; create new poses of exactly the SAME elf girl, not a redesign.
Preserve her silver-white long braided hair, green eyes, pointed ears, delicate white flower/leaf crown, green leaf dress, pale translucent green leaf wings and pale boots. Same cute chibi proportions and polished detailed soft anime illustration style. Full body visible in every cell, tasteful original costume unchanged.
Output a single landscape PNG with TRUE ALPHA TRANSPARENCY, preferably 1536x1024, aspect ratio exactly 3:2. STRICT invisible uniform grid of SIX columns and FOUR rows (24 frames). Each cell is square. NO grid lines, NO labels, NO text, NO checkerboard baked in, NO backdrop, NO shadows outside the character. Each cell contains exactly ONE full-body elf. All 24 figures have the same scale, head size, frontal camera, lighting, palette and central anchor; feet baseline at 90% cell height, crown at 8% cell height. Keep wings and limbs INSIDE their own cell, 8% clear gutters. No floating icons, no props. Precision sprite alignment matters.
Each ROW is one complete six-frame seamless animation loop read LEFT TO RIGHT. Draw six distinct incremental poses and facial movements, not six copies. Keep frame-to-frame changes small, anatomical, continuous, returning smoothly from frame6 to frame1; body/face identity must not drift. Use rounded smooth arcs and follow-through in hair and wing movement. The four rows have DIFFERENT prescribed actions.
ROW 1: IDLE BREATHING AND BLINKING: gentle neutral smile, hands resting in front, subtle chest breathing, eyes open / half closed / closed / half open / open / open, tiny wing sway. ROW 2: HAPPY: bright smile growing to closed-eye laugh with hands clasped near chest, then reopening eyes and settling. ROW 3: SHY: cheeks lightly blushing, chin dips, hands clasp together, head small tilt right, glance downward then returning. ROW 4: SAD: gentle downturned mouth and eyebrows, chin dips, hands together low, then looks up slightly. No tears or symbols.
```
