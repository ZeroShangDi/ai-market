# AI 基础包与旧功能对照

检查日期：2026-10-23。范围：本地源码与契约对照；本次未调用真实模型、音频设备或部署服务。以下“已有”仅指实现存在，不代表端到端验收。

| 结论 | 判断 |
|---|---|
| 三包是否足以作为基础 | 是：voice 管音频，chat 管对话，work 管后台执行与交互，边界可保留 |
| 是否已能替代旧 AI 功能 | 否：缺外部能力实现及应用集成，部分执行语义也弱于旧实现 |
| 是否需要第四个基础包 | 暂无必要；先接通一个真实闭环，再按复用需要提取 |
| 是否需要增加大量公开方法 | 暂无必要；优先完善现有参数、事件与注入协议 |

## 必需的外部实现

| 能力 | 当前情况与缺口 | 建议归属 | 优先级 |
|---|---|---|---|
| 聊天模型 | chat 要求外部 generator；包自身不能请求模型，plugins 也不会自动执行 | 外部模型适配器：流式请求、工具调用循环与取消 | 接通前 |
| 联网、技能、角色、记忆 | 已有注入口，不等于已有搜索或技能执行器；work 的 WorkTool 是函数工具契约，不是完整技能装载系统 | 可复用插件及宿主装载；chat 保持轻量 | 联网与工作控制先做，其余按需 |
| 真正执行工作 | 两种 SDK 已接入，但 Claude 原生工具被禁用，只能调用注入工具；没有工具就不能完成旧版读写文件、执行命令和资料制作 | 外部工具插件、文件工作区与隔离运行环境 | 接通前 |
| 语音对话编排 | voice 不生成回答；尚缺识别→chat、文本分句→播报、打断→取消生成的关联 | 应用组合层 | 接通前 |
| 语音控制工作 | 缺创建/查询/续聊/答复待办、完成后汇报的实际插件与事件连接 | 工作控制插件调用 work；应用协调展示和播报 | 接通前 |
| 手机音频连接 | 有终端音频注入口、浏览器 AEC 辅助；缺旧版 WebRTC 服务、票据、媒体转发和格式转换；本地 PortAudio 无 AEC | 运行宿主和客户端终端适配器 | 手机语音接入前 |
| 持久化和文件 | store、资源引用、产物发布是端口；缺正式数据库适配、附件上传下载与访问校验 | 宿主基础设施；按身份隔离实例与存储 | 正式使用前 |
| 服务接口与权限 | 包内方法不等于 HTTP/SSE 服务；身份、授权、审批凭证校验由外部注入 | 服务宿主；语音与工作台调用同一授权用例 | 正式使用前 |
| 页面与角色动作 | 包不提供工作台、会话页面、桌宠状态与动作映射 | 客户端和应用层 | 按原功能迁移 |

## 基础协议和适配器对照（流式与恢复已更新）

| 差距 | 现状及影响 | 最小建议 |
|---|---|---|
| 工作过程输出 | 已补两个 SDK 文本流及 stream_events，状态/待办/产物事件可按持久游标重放 | 宿主 SSE 尚未接入；不透传全部供应商原始事件 |
| 工作续接 | 已补 OpenAI 完整工具上下文恢复、Claude 原生会话引用；重启标记中断，显式 submit 续办 | 不保证在途副作用恰好一次；Claude 依赖宿主持久会话文件，真实环境待验收 |
| 重试幂等 | 没有旧接口 request_id 对应的提交去重语义；手机重发可能创建重复执行 | 宿主持久化请求映射；明确映射与任务提交的原子性，必要时补现有提交参数 |
| 取消确认 | SDK 适配器不确认全部远端副作用停止；当前按不确定中断处理 | 保留真实语义，外部工具支持协作取消，结果不确定时核对回执 |
| 长历史和持久化成本 | load_all 加载全部记录；chat 全量历史进入生成器，逐增量保存快照；不适合直接扩大规模 | 先由生成器控制模型上下文；有规模需求时扩展分页/按需加载与保存策略 |
| 服务生命周期 | 缺统一关闭全部会话/订阅/客户端的公开生命周期；实例有单写者假设 | 宿主先负责停机收尾和实例隔离，再按真实集成需要补清理入口 |

## 推荐接通顺序

| 顺序 | 交付 | 完成标准 |
|---|---|---|
| 1 | 聊天模型适配器＋一个搜索插件 | 真实流式回答、搜索引用、取消有效 |
| 2 | work 工具插件＋资源发布＋存储适配 | 真实生成一个可下载文件；审批拒绝无副作用；重启状态正确 |
| 3 | 工作控制插件＋应用编排 | 聊天创建任务、返回回执后继续聊天、任务完成可查询及汇报 |
| 4 | 语音与终端连接 | 手机实际出声；打断后旧回答不再播报；同一待办可从语音或工作台答复 |
| 5 | 重试、断线与恢复验收 | 重发不重复执行；断线可重连查询；中断续做行为符合声明 |
